## 11월 12일 - 이진 트리

### 오늘 배운 내용

이진 트리는 하나의 노드가 최대 두 개의 자식 노드를 가질 수 있는 자료구조이다.
각 노드는 데이터를 저장하는 `data`와 왼쪽 및 오른쪽 자식을 가리키는 `left`, `right`를 가진다.

### 노드의 구성

```py
class TreeNode:
    def __init__(self):
        self.data = None
        self.left = None
        self.right = None
```

- `data`: 노드에 저장할 값
- `left`: 왼쪽 자식 노드
- `right`: 오른쪽 자식 노드
- `None`: 연결된 자식 노드가 아직 없다는 뜻

### 트리 연결 방법

노드를 각각 만든 다음 부모 노드의 `left` 또는 `right`에 자식 노드를 연결한다.

```py
node1 = TreeNode()
node1.data = "커피"

node2 = TreeNode()
node2.data = "우유"
node1.left = node2

node3 = TreeNode()
node3.data = "녹차"
node1.right = node3
```

위 코드는 다음 구조를 만든다.

```text
       커피
      /   \
    우유   녹차
```

### 완성된 트리 구조

```text
          커피
        /      \
      우유      녹차
     /   \       /
   라떼  카페모카 아이스티
```

- `커피`: 루트 노드
- `우유`, `녹차`: 루트의 자식 노드
- `라떼`, `카페모카`, `아이스티`: 자식의 자식 노드
- `아이스티`처럼 한쪽 자식만 있는 노드도 만들 수 있다.

### 노드에 접근하기

`.`을 사용해 연결된 노드를 따라가며 원하는 데이터에 접근할 수 있다.

```py
print(node1.data)                # 커피
print(node1.left.data)           # 우유
print(node1.right.data)          # 녹차
print(node1.left.left.data)      # 라떼
print(node1.left.right.data)     # 카페모카
print(node1.right.left.data)     # 아이스티
```

### 기억할 점

이진 트리는 배열의 인덱스가 아니라 노드의 `left`, `right` 연결을 이용해 구조를 표현한다.
따라서 노드를 연결할 때 부모와 자식의 방향을 정확하게 지정해야 한다.

## 11월 5일 - 원형 큐

### 오늘 배운 내용

큐는 **먼저 들어온 데이터가 먼저 나가는 FIFO(First In, First Out)** 자료구조이다.
원형 큐는 배열의 끝에 도달하면 다시 처음으로 돌아가서 빈 공간을 재사용한다.

### 큐의 위치 관리

- `front`: 가장 먼저 나갈 데이터의 위치
- `rear`: 가장 최근에 들어온 데이터의 위치
- 다음 위치는 `(현재 위치 + 1) % 큐 크기`로 계산한다.
- `front == rear`이면 큐가 비어 있다.
- `(rear + 1) % size == front`이면 큐가 가득 찬 상태이다.

현재 구현은 빈 공간 하나를 구분용으로 사용하기 때문에 `Queue(5)`를 만들어도 실제로 저장할 수 있는 데이터는 4개이다.

### 주요 연산

| 연산 | 하는 일 |
|---|---|
| `enqueue(data)` | 큐의 뒤에 데이터를 추가한다. |
| `dequeue()` | 큐의 앞에서 데이터를 꺼낸다. |
| `peek()` | 데이터를 꺼내지 않고 다음 데이터를 확인한다. |
| `is_empty()` | 큐가 비어 있는지 확인한다. |
| `is_full()` | 큐가 가득 찼는지 확인한다. |

### 실행 흐름

```py
queue = Queue(5)
queue.enqueue("화사")
queue.enqueue("솔라")

print(queue.peek())     # 솔라가 아니라 화사
print(queue.dequeue())  # 화사
```

`dequeue()`로 앞쪽 공간이 비어도 `rear`가 배열의 끝에서 처음으로 돌아가기 때문에 그 공간을 다시 사용할 수 있다.

## 10월 29일 - 스택

### 오늘 배운 내용

스택은 **나중에 들어온 데이터가 먼저 나가는 LIFO(Last In, First Out)** 자료구조이다.
접시를 쌓고 위에서부터 꺼내는 모습을 생각하면 이해하기 쉽다.

### 스택의 관리 방법

- 리스트에 데이터를 저장한다.
- `top`은 스택의 가장 위에 있는 데이터 위치를 나타낸다.
- 처음에는 스택이 비어 있으므로 `top = -1`로 시작한다.
- `push()`를 하면 `top`을 1 증가시킨 뒤 데이터를 저장한다.
- `pop()`을 하면 가장 위의 데이터를 꺼낸 뒤 `top`을 1 감소시킨다.

### 주요 연산

| 연산 | 하는 일 |
|---|---|
| `push(data)` | 스택의 맨 위에 데이터를 넣는다. |
| `pop()` | 스택의 맨 위 데이터를 꺼낸다. |
| `peek()` | 맨 위 데이터를 확인하지만 꺼내지는 않는다. |
| `is_full()` | 스택이 가득 찼는지 확인한다. |
| `is_empty()` | 스택이 비어 있는지 확인한다. |

```py
stack = [None] * 5
top = -1

push("커피")
push("녹차")
print(peek())  # 녹차
pop()          # 녹차 제거
```

스택이 가득 찼는데 `push()`하거나 비어 있는데 `pop()`하면 오류가 발생할 수 있으므로 연산 전에 상태를 확인해야 한다.

## 10월 15일 - 원형 연결 리스트

### 오늘 배운 내용

연결 리스트의 마지막 노드가 첫 번째 노드를 가리키도록 연결하면 **원형 연결 리스트**가 된다.
따라서 마지막 노드의 `link`는 `None`이 아니라 항상 `head`를 가리킨다.

### 구조

- `Node`는 데이터와 다음 노드를 가리키는 `link`를 가진다.
- `head`는 첫 번째 노드를 가리킨다.
- 빈 리스트에서는 `head = None`이다.
- 첫 노드를 추가하면 그 노드의 `link`가 자기 자신을 가리킨다.
- 마지막 노드를 추가하면 마지막 노드의 `link`를 `head`로 연결한다.

```py
class CircularLinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            new_node.link = self.head
            return
```

### 기억할 점

일반 연결 리스트는 `current.link is None`일 때 끝나지만, 원형 연결 리스트는 다시 `head`로 돌아왔을 때 순회를 멈춰야 한다.

## 10월 8일 - 연결 리스트 함수화와 검색

### 오늘 배운 내용

10월 1일에 직접 만들었던 연결 리스트를 함수로 정리했다.
반복해서 사용할 수 있도록 노드 출력, 검색, 삽입 기능을 각각 함수로 만들었다.

### 사용하는 변수

- `head`: 연결 리스트의 첫 번째 노드
- `current`: 현재 탐색 중인 노드
- `pre`: `current` 바로 앞의 노드
- `memory`: 생성한 노드들을 저장하는 공간

### 주요 함수

| 함수 | 하는 일 |
|---|---|
| `print_nodes()` | `head`부터 마지막 노드까지 출력한다. |
| `find_data(data)` | 원하는 데이터를 가진 노드를 검색한다. |
| `insert_node(pre_data, data)` | 특정 데이터 앞에 새 노드를 삽입한다. |

### 검색 과정

1. `current`를 `head`로 설정한다.
2. 현재 노드의 데이터가 찾는 값인지 확인한다.
3. 아니면 `current = current.link`로 다음 노드로 이동한다.
4. 찾으면 해당 노드를 반환하고, 끝까지 못 찾으면 빈 노드를 반환한다.

```py
def find_data(find_data):
    current = head
    if current.data == find_data:
        return current

    while current.link is not None:
        current = current.link
        if current.data == find_data:
            return current

    return Node()
```

### 노드 삽입

새 노드를 중간에 넣을 때는 기존 연결을 끊고 다음 순서로 다시 연결한다.

```text
pre -> current
pre -> new_node -> current
```

첫 번째 노드 앞, 중간, 마지막 뒤에 삽입하는 경우에는 연결해야 하는 대상이 다르므로 각각 처리해야 한다.
함수를 호출할 때마다 `current`와 `pre`를 초기화해야 이전 탐색 결과가 남지 않는다.

## 10월 1일 - 리스트와 연결 리스트 기초

### 리스트 기본 조작

파이썬 리스트는 인덱스로 원하는 위치의 데이터에 바로 접근할 수 있다.
`append()`는 리스트의 마지막에 데이터를 추가하고, `len()`은 리스트의 길이를 반환한다.

```py
kakao = []
kakao.append("다현")
kakao.append("정연")

for i in range(len(kakao)):
    print(kakao[i], end=", ")
```

### 연결 리스트의 기본 구조

연결 리스트는 여러 개의 노드가 링크로 연결된 자료구조이다.
각 노드는 실제 데이터인 `data`와 다음 노드를 가리키는 `link`를 가진다.

```py
class Node:
    def __init__(self):
        self.data = None
        self.link = None
```

노드를 순서대로 연결하면 `head`에서 시작해 `link`를 따라가며 전체 데이터를 확인할 수 있다.
중간에 노드를 삽입할 때는 앞 노드의 `link`가 새 노드를 가리키도록 바꾸고, 새 노드의 `link`는 뒤 노드를 가리키도록 한다.

## 9월 17일 - 리스트의 삽입과 삭제

### 오늘 배운 내용

- 인덱스를 사용해 리스트의 원하는 위치에 접근하기
- `append()`로 마지막에 데이터 추가하기
- 데이터를 한 칸씩 이동해 원하는 위치에 삽입하기
- 데이터를 한 칸씩 이동해 원하는 항목 삭제하기
- 임시 변수로 두 데이터의 위치 바꾸기

### 데이터 삽입 원리

리스트 중간에 새 데이터를 넣으려면 삽입 위치 뒤의 데이터를 뒤에서부터 한 칸씩 이동시켜야 한다.
앞에서부터 이동하면 기존 데이터가 덮어써질 수 있으므로 뒤에서부터 이동하는 것이 안전하다.

```py
kakao = ["가나", "다라", "마바", "사아", "자차"]
kakao.append("삽입")

temp = kakao[4]
kakao[4] = kakao[5]
kakao[5] = temp
```

### 데이터 삭제 원리

데이터를 삭제한 뒤에는 삭제된 위치 뒤의 데이터를 한 칸씩 앞으로 이동해 빈자리를 채운다.
리스트의 순서를 바꿀 때는 임시 변수에 값을 저장한 후 두 값을 교환한다.
